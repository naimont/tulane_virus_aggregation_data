# tulane_virus_aggregation_data
This repository contains Plaque assay data measuring virus infectivity after a 5-hour of exposure at 1, 10, and 100 mM CaCl2, along with control samples, Size measurement data at different CaCl2 concentrations and pH values are provided, and zeta potential data measuring the net charge of the virus at different pH values and CaCl2 concentrations.
